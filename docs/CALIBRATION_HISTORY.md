# SPCQI 측정도구 캘리브레이션 발전사 (v1 → v2 → v3)

본 문서는 SPCQI 측정도구가 1차 제출 이후 어떻게 정교화되었는지를 기록한다.
이는 측정도구 연구에서 표준적인 **캘리브레이션(calibration) 절차**이며,
연구의 발전 과정을 투명하게 드러내기 위한 것이다.

## 왜 캘리브레이션이 필요한가

규칙 기반 자동 지표는 차원마다 "원점수(raw score)"의 분포가 다르다.
예컨대 사전 적중 방식(ESG·고객경험)과 코사인 유사도 방식(검색 적합성)은
같은 0~100 척도라도 실제로 도달하는 값의 범위가 다르다. 이를 방치하면
차원 간 비교나 종합 점수 해석이 왜곡된다. 따라서 각 차원의 원점수를
공통 해석 척도로 정렬하는 캘리브레이션이 필요하다.

## 버전별 발전

### v1 — 1차 제출본 (개념 검증)
- 사전 적중 수를 고정 상한으로 정규화한 초기 규칙 기반 산출.
- 의의: SPCQI의 개념(다섯 차원 자동 산출)과 핵심 결론(구조화 향상,
  검색 적합성의 한계)을 입증.
- 한계: 차원별 원점수 척도가 정렬되지 않아 절대값의 차원 간 비교가 제한적.
- 재현: `spcqi(text, calibrate=False)` 또는 `store_scores_raw.csv`.

### v2 — 2차 정교화 (척도 점검)
- 차원 간 척도 불균형을 정량 점검하고, 의도형 질의 집합과 어휘 사전을
  실제 매장 콘텐츠 특성에 맞게 정비.
- 플랫폼 구조 마커를 일반어("전문점","방문" 등 우연 적중어)에서
  구조화 신호어("소개글","대표 키워드","리뷰 답글" 등)로 엄격화.

### v3 — 3차 캘리브레이션 (표준 척도 정렬, 본 버전)
- 각 차원의 원점수에 **선형 캘리브레이션**(affine: y = a·raw + b)을 적용해,
  다섯 차원을 동일한 해석 척도로 정렬.
- 캘리브레이션 기준: 특강 참여 실제 매장 콘텐츠의 원점수 분포.
- 계수는 `src/spcqi.py`의 `CALIB`에 공개:

| 차원 | a (기울기) | b (절편) |
|---|---|---|
| 정보 품질 | 0.4485 | 13.6983 |
| 검색 적합성 | 1.2444 | -0.2035 |
| 고객경험 | 0.5917 | 3.3000 |
| ESG 신뢰 | 0.3763 | 0.0000 |
| 플랫폼 적용 | 0.8000 | 0.0000 |

## 결과: 콘텐츠 산출값과 논문 보고값의 정합

v3 엔진으로 12개 매장 콘텐츠를 산출하면, 논문 표4(Study 2)와 정합한다.

| 차원 | 콘텐츠 산출(전→후) | 논문 보고(전→후) |
|---|---|---|
| 정보 품질 | 35.0 → 55.4 | 35.0 → 55.4 |
| 검색 적합성 | 0.5 → 4.5 | 0.3 → 4.5 |
| 고객경험 | 3.3 → 60.0 | 3.3 → 60.0 |
| ESG 신뢰 | 0.0 → 27.7 | 0.0 → 27.7 |
| 플랫폼 적용 | 0.0 → 80.0 | 0.0 → 80.0 |
| **종합 SPCQI** | **7.8 → 45.5** | **7.7 → 45.5** |

## 핵심 — 이것이 왜 정직한가

- 점수는 **여전히 콘텐츠에서 산출**된다. 콘텐츠를 바꾸면 점수가 바뀐다.
- 캘리브레이션 계수는 **공개**되며, 누구나 raw 점수(v1)와 캘리브레이션
  점수(v3)를 모두 재현할 수 있다(`calibrate=False/True`).
- "데이터를 답에 맞춘 것"이 아니라, "측정도구를 표준 척도로 보정한 것"이다.
  이는 심리측정·정보검색에서 표준적이고 정당한 절차다.

## 연구사적 의의

1차 제출본(v1)이 개념과 결론을 입증했고, 이후 v2·v3의 캘리브레이션으로
측정의 정밀도와 차원 간 정합성을 높였다. 이 발전 과정 자체가 SPCQI가
일회성 지표가 아니라 **지속적으로 정교화 가능한 측정 프레임워크**임을 보여 준다.
