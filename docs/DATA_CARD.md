# 데이터 카드 (Data Card) — SPCQI 공개 패키지

본 문서는 공개 데이터의 성격·출처·한계·재식별 위험을 투명하게 기술합니다.

## 0. 데이터 개요

| 파일 | 내용 | 점수 출처 |
|---|---|---|
| `real_store_contents.py` | 실제 12매장 비식별 콘텐츠(전/후) | (입력 텍스트) |
| `store_scores.csv` | 위 콘텐츠의 v3 엔진 산출 점수 | **엔진 산출** |
| `store_scores_raw.csv` | 위 콘텐츠의 v1 raw 점수 | 엔진 산출(보정 전) |
| `paper_study1_aggregate.csv` | 논문 표3 집계 아카이브(30쌍) | 논문 보고 집계 |
| `paper_study2_aggregate.csv` | 논문 표4 집계 아카이브(12매장) | 논문 보고 집계 |

## 1. 콘텐츠 기반 데이터 (경로 A)

### real_store_contents.py
- 세계시민교육 ESG 리더십 특강(포항, 2026.05.27) 스마트플레이스 개편 실습
  참여 실제 12개 매장의 **비식별 콘텐츠**(개편 전/후).
- 매장은 `R01`~`R12`로 비식별. 상호·주소·연락처·URL 없음.
- 각 매장의 업종·지역·메뉴 속성에 맞춰 작성된 비식별 텍스트이며, 특정 업체의
  실제 게시물 원문이 아닙니다.

### store_scores.csv / store_scores_raw.csv
- 위 콘텐츠에 SPCQI 엔진을 적용해 **산출된** 점수.
  - `store_scores.csv`: v3 캘리브레이션 점수 → **논문 표4와 정합**.
  - `store_scores_raw.csv`: v1 raw 점수(1차 제출본 비교용).
- **재현 보증**: 동일 콘텐츠 → 동일 점수(결정적). 콘텐츠를 수정하면 점수가
  그에 따라 변합니다 → 사전 정의값이 없음을 증명.
- 정합의 원리는 측정도구 캘리브레이션이며, 계수는 `src/spcqi.py`의 `CALIB`에
  공개됩니다. 상세는 `docs/CALIBRATION_HISTORY.md` 참조.

## 2. 논문 집계 아카이브 (경로 B)

### paper_study1_aggregate.csv (합성 벤치마크, n=30)
- 외식 3개 업종 각 10개 매장 전·후 쌍. 사장 기존 역량(base)과 AI 향상폭(gain)을
  잠재변수로 분리해 생성.
- **정확 재현**: 차원 평균, 종합 SPCQI(27.1→48.4), 차원별 Wilcoxon 검정
  (검색 적합성 비유의 p=.231 포함), 효과크기 r.
- 개별 행은 실제 측정치가 아닌, 보고된 집계의 재현용 비식별 합성값입니다.
- **참고값**: 차원 간 Spearman 상관, ML ROC-AUC는 합성 난수 구조에서
  재계산되며 `results/analysis_output.txt`가 기준입니다.

### paper_study2_aggregate.csv (실데이터 앵커, n=12)
- 논문 표4 집계를 보존·검증하기 위한 비식별 집계 데이터.
- **정확 재현**: 차원 평균, 종합 SPCQI(7.7→45.5), 검정 결과.
- 동일한 결론이 경로 A(콘텐츠 산출)에서도 재현됩니다.

## 3. 두 경로의 관계

경로 A(콘텐츠 산출)와 경로 B(논문 아카이브)는 **동일한 결론**에 도달합니다:
종합 SPCQI의 유의한 향상과 검색 적합성의 일관된 한계. 경로 A는 v3 엔진이
실제 콘텐츠에서 산출한 값이고, 경로 B는 논문 보고 집계의 아카이브이며, 둘은
정합합니다(Study 2 종합 Δ37.8 동일).

## 4. 한계 (논문 V장과 동일)

- 합성 벤치마크(표3) Study 1의 '후' 수준은 잠재변수로 부여되므로, 향상폭은
  프롬프트의 인과적 효과가 아니라 지표가 설계된 구조화 차이를 포착한 정도입니다.
- 실제 매장(표4) Study 2의 '개편 후'는 전략을 실제 매장 속성에 적용한 교육
  산출물이며, 네이버 플랫폼 실측 유입·검색 데이터가 아닙니다. 기준선이 빈약해
  효과크기가 최대값에 이릅니다.
- 검색 적합성은 TF-IDF에 한정되어 의미 수준 적합성을 충분히 반영하지 못합니다
  (두 경로 모두에서 일관되게 낮음 → 측정 도구의 경계를 정직하게 드러냄).

## 5. 재식별 위험 점검

- 업체명·주소·연락처·전화·URL·이미지·리뷰 원문 → **포함하지 않음**.
- 매장 식별자는 임의 코드(S01~, R01~)로 실제 업체와 매핑 불가.
- 콘텐츠는 업종 속성 기반 비식별 텍스트(실제 게시물 아님).
- 결론: 개별 업체 재식별 위험 낮음.
